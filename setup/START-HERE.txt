ADTD Modern 3.0 - offline package
==================================

Draws your Active Directory in draw.io and writes a health, security and
Microsoft Entra ID hybrid-readiness report. Read-only: it never changes AD.
Needs no internet access.

WHERE TO RUN IT
  Any domain-joined Windows 10/11 or Windows Server 2016+ computer
  (an admin workstation or management server is ideal; a DC also works).
  Log on with a normal domain user account - no AD admin rights needed.
  The computer must reach a domain controller on TCP 389 and TCP 3268.
  Not domain-joined? Use:  Invoke-ADTD -Server <dc> -Credential (Get-Credential)

WHAT'S IN THIS FOLDER
  ADTD_Modern_Setup_3.0.3.msi   Installer (needs local admin)
  setup\Install-ADTD.ps1        Install for the current user only (no admin)
  setup\Install-Prerequisites.ps1  Status check + install draw.io desktop
  drawio\                       Put the draw.io desktop installer here
  src\                          The tool itself (can run without installing: src\ADTD.exe)
  docs\                         Guides (OFFLINE.md, INSTALL.md, USAGE.md, ...)
  samples\                      Example report and drawing (fictional forest)

STEPS
  1. Unblock the files (they came from the internet):
       Get-ChildItem -Recurse | Unblock-File
  2. Install:
       - with admin:    double-click ADTD_Modern_Setup_3.0.3.msi
       - without admin: powershell -ExecutionPolicy Bypass -File .\setup\Install-ADTD.ps1
  3. Check prerequisites and install draw.io desktop (optional, recommended):
       powershell -ExecutionPolicy Bypass -File .\setup\Install-Prerequisites.ps1
     Choose 1. It installs draw.io from the file in the drawio folder
     (download draw.io-<version>-windows-installer.exe from
      https://github.com/jgraph/drawio-desktop/releases on a computer with internet).
  4. Run:
       Start menu > ADTD Modern  (tick "No internet on this computer", then
       click "Draw my Active Directory"), or
       Invoke-ADTD -All -Format DrawIo, Html, HtmlTabs, Markdown, Csv, Json -Offline -Open
  5. Results: Documents\ADTD
       ...-tabs.html   tabbed report (diagrams work offline)
       ...drawio       drawing for draw.io desktop
       ...-findings\   one report per finding

Run without installing:
  powershell -ExecutionPolicy Bypass -File .\src\ADTD.ps1 -All -Format DrawIo, HtmlTabs, Csv -Offline

The reports contain account names and security weaknesses - handle them as
sensitive documents.
