# S27: Computers run an unsupported Windows version

**Severity:** High · **Category:** Security · **Area:** Devices · **Roadmap phase:** 1 · **Forest:** contoso.com

## What ADTD found

2 computer(s) run an unsupported Windows version: contoso.com\WS02 (Windows 10), contoso.com\OLD01 (Windows Server 2012 R2).

## Why it matters

Unsupported systems get no security fixes and are the easiest way in.

## How to fix

1. Upgrade or retire these computers; isolate any that must stay on a restricted network segment.

## Affected objects (2)

- contoso.com\WS02 (Windows 10)
- contoso.com\OLD01 (Windows Server 2012 R2)
