ADTD Modern 3.0

Active Directory Topology Diagrammer, rebuilt for Windows Server 2016, 2019, 2022 and 2025, with a security assessment and a Microsoft Entra ID hybrid upgrade plan. It replaces Microsoft's ADTD 2011 (ADTD.Net_Setup.msi), which stopped at Windows Server 2008 R2, Exchange 2010 and Visio 2003–2010. It is not a Microsoft product.

The assessment

  • 58 checks: 18 health, 32 security and 8 hybrid readiness. Each finding comes with what was found, the affected objects, why it matters, step-by-step fixes and Microsoft references.
  • Security examples:
    • Tier 0 membership, Protected Users and krbtgt age
    • Kerberoasting and AS-REP roasting
    • Unconstrained delegation, and RC4/DES
    • Stale accounts, LAPS coverage and unsupported Windows
    • MachineAccountQuota and password policy
    • AD CS ESC1-style templates
    • Seamless SSO key age
  • Hybrid readiness: detects Entra Connect or Cloud Sync, hybrid join and tenant, Seamless SSO, Entra Kerberos, AD FS, Password Protection and UPN suffixes. It shows what on-premises AD is missing, with a target topology and a roadmap.
  • Reports:
    • HTML, as a single page or tabbed: Summary, Findings, Diagrams, Hybrid plan, Inventory
    • One Markdown file per finding
    • CSV and JSON

Domain controllers are coloured by support: green is supported, orange means support ends within 12 months, red means out of support. Read-only domain controllers have a dashed border.

What's new compared with ADTD 2011

  • Recognises Windows Server 2012 to 2025: functional levels up to 10 and schema versions up to 91.
  • Recognises Exchange 2013, 2016, 2019 and Exchange Server Subscription Edition, and DAGs. The old routing groups are gone.
  • Drawings are .drawio files for draw.io desktop or draw.io on the web, which are both free. Each run also saves a link that opens the drawing in app.diagrams.net. Visio is optional: with Visio 2013 or later, ADTD can also draw straight into Visio.
  • Adds an HTML health report plus CSV and JSON exports. A saved JSON inventory can be redrawn later without connecting to Active Directory.
  • Checks for out-of-support domain controllers, FRS SYSVOL, the Recycle Bin being off, single-DC domains, sites without links or subnets, unassigned subnets, SMTP site links, trusts without SID filtering, and unsupported Exchange servers.
  • Runs on Windows PowerShell 5.1 or PowerShell 7. It doesn't need .NET 2.0, RSAT or the ActiveDirectory module.

Requirements

  • A Windows 10/11 or Windows Server 2016+ computer that is joined to the domain, or can reach it (choose Sign in as: A different account).
  • Any domain user account. ADTD only reads the directory and never changes it. Exchange and DFS-R pages need read access to those containers, which authenticated users have by default.
  • A viewer: draw.io desktop or draw.io on the web. Run Start → ADTD Modern - Prerequisites to install draw.io desktop, choose draw.io on the web, or optionally install Visio (needs a licence).

Use it

Window: Start menu → ADTD Modern. Connect (your Windows account or a different one, with Test connection), pick the pages and output formats, then click Draw my Active Directory. About shows the install location and adds a desktop shortcut or taskbar pin. By default, results are saved to Documents\ADTD.

PowerShell:

Invoke-ADTD                                   # summary, sites, replication, domains, hybrid
Invoke-ADTD -All -Format DrawIo, Html, HtmlTabs, Markdown, Csv, Json -Open
Invoke-ADTD -Open -DrawIoViewer Web           # open the drawing in draw.io on the web
Invoke-ADTD -Server dc01.contoso.com -Credential (Get-Credential)
Invoke-ADTD -Drawings Sites, OUs -MaxOUs 1000
Invoke-ADTD -InputFile .\ADTD-contoso.com-20260927-1015.json -Format Visio   # redraw offline
Get-Help Invoke-ADTD -Full

Install and remove

  • MSI: run ADTD_Modern_Setup_3.0.2.msi (admin). It installs the module for all users in C:\Program Files\WindowsPowerShell\Modules\ADTD and adds the app (ADTD.exe) with Start menu shortcuts. A welcome screen then offers a desktop shortcut and a taskbar pin. A newer MSI replaces the old one automatically. Remove it in Settings → Apps. For a silent install, use msiexec /i ADTD_Modern_Setup_3.0.2.msi /qn.
  • Without admin rights: powershell -ExecutionPolicy Bypass -File Install-ADTD.ps1 installs for the current user only. Use -Uninstall to remove it.
  • The scripts are not code-signed. If your execution policy is AllSigned, sign them with your code-signing certificate, or use the Start menu shortcut, which runs with -ExecutionPolicy Bypass for that process only.

Keeping it current

Every version table (functional levels, schema versions, Windows Server builds and support dates, Exchange builds) is in ADTD.Versions.ps1. When Microsoft ships a new release, add a row there. Nothing else needs to change.
